## Project Description
This is an Android Tip Calculator application developed using Kotlin and Jetpack Compose. The application calculates tips, total bills, and the amount each person pays when a bill is shared.

## Features
- Enter a bill amount.
- Select a tip percentage or enter a custom tip.
- Split the bill among multiple people.
- Calculate tip amount and total bill.
- Calculate the amount each person pays.
- Round each person's payment upward using the personalized rounding increment.
- Reset the calculator, clearing the bill amount and restoring the tip percentage to 16%.

## Technologies Used
- Kotlin
- Android Studio
- Jetpack Compose
